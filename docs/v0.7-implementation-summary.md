## What Was Built

### Core Features

1. **Phase 2.7: Re-evaluation Pipeline**
   - Added after Phase 2 (recommendation generation) and before final ranking
   - For each recommendation, retrieves literature evidence and re-evaluates with LLM
   - Can confirm, downgrade confidence, or suppress recommendations entirely
   - Conservative by design: downgrades or suppresses when evidence is weak/contradictory

2. **Evidence-Based Decision Making**
   - Structured assessment of literature quality
   - Checks if evidence supports both the original issue and the proposed alternative
   - Evaluates context match (strong/partial/weak/none)
   - Flags presence of quantitative data (yields, selectivity, etc.)

3. **Rationale Revision**
   - LLM updates recommendation rationale based on actual literature findings
   - Adds concerns as caveats when evidence is insufficient
   - Prevents overconfident recommendations based on general knowledge

### Key Functions

#### `reevaluateRecommendation()`
```typescript
async function reevaluateRecommendation(
  recommendation: Recommendation,
  literatureEvidence: SearchResult[]
): Promise<ReevaluationResult | null>
```

- Takes a recommendation and retrieved literature
- Calls Claude with structured re-evaluation prompt
- Returns action (confirm/downgrade/suppress) and revised metadata
- Gracefully handles API failures (returns null, keeps original recommendation)

#### `reevaluateAllRecommendations()`
```typescript
async function reevaluateAllRecommendations(
  recommendations: Recommendation[],
  onProgress?: (event: ProgressEvent) => void
): Promise<{ 
  recommendations: Recommendation[]
  stats: { confirmed: number; downgraded: number; suppressed: number; failed: number }
}>
```

- Batch re-evaluation of all recommendations
- Sequential processing to avoid rate limits
- Progress events for UI updates
- Returns filtered recommendations list (suppressed ones removed) and stats

## Conservative Re-evaluation Rules

The prompt enforces strict evidence requirements:

1. **Suppress if:**
   - Literature directly contradicts the recommendation
   - Alternative is shown to be worse than original
   - No context match (wrong chemistry domain)

2. **Downgrade if:**
   - Literature doesn't mention the alternative
   - Evidence is purely qualitative with no data
   - Context match is weak or partial
   - No literature was found at all

3. **Confirm if:**
   - Literature explicitly supports the substitution
   - Quantitative data shows comparable or better results
   - Chemistry context matches closely
   - Multiple sources corroborate the recommendation
